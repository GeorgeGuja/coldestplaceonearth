<task type="checkpoint:human-action" gate="blocking">
  <what-automated>
    All code changes are committed to git. render.yaml is at project root with correct Render config:
    - Build: npm install && npm run build
    - Start: npm start
    - Plan: free (Node environment)
  </what-automated>
  <manual-steps>
    Deploy ColdestPlace to Render:

    1. Go to https://render.com and sign up for a free account (or log in)
    2. Click "New +" → "Web Service"
    3. Connect your GitHub account and select the ColdestPlace repository
    4. Render will detect render.yaml automatically — confirm these settings appear:
         Name: coldestplace
         Environment: Node
         Build Command: npm install && npm run build
         Start Command: npm start
         Plan: Free
    5. Click "Create Web Service"
    6. Wait for the first build to complete — watch the "Logs" tab (takes 3–5 minutes)
    7. Once build shows "Deploy live for ...", note your service URL
       It will be something like: https://coldestplace.onrender.com

    ⚠️ The first request to /api/coldest after deploy may take 60s (cache warming). This is expected.
  </manual-steps>
  <resume-signal>Paste your Render service URL (e.g. https://coldestplace.onrender.com) to continue</resume-signal>
</task>
