  </what-automated>
  <manual-steps>
    Create a free UptimeRobot monitor:

    1. Go to https://uptimerobot.com and create a free account (or log in)
    2. Click "Add New Monitor"
    3. Configure the monitor:
         Monitor Type: HTTP(s)
         Friendly Name: ColdestPlace
         URL: https://{your-render-url}/api/coldest   ← use the URL from Plan 02
         Monitoring Interval: 14 minutes
    4. Click "Create Monitor"
    5. The monitor will briefly show "Paused", then switch to "Up" (green) on its first check

    Why /api/coldest and not /? The API endpoint exercises the full app (not just static files),
    and the JSON response confirms the cron cache is working. UptimeRobot's ping also counts as
    a request, keeping the Render instance warm.
  </manual-steps>
  <resume-signal>Type "done" once the UptimeRobot monitor is created and showing a status</resume-signal>
