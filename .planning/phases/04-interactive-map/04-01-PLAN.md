# Phase 4: Interactive Map — Plan 04-01

## Goal

Add a Leaflet.js interactive map below the top-5 list that pins all 6 coldest locations
(hero + top-5) with popups and a click-to-scroll-highlight interaction — pure frontend,
no backend changes, no API keys.

## Scope

**Files modified:**
- `public/index.html` — Add Leaflet 1.9.4 CDN `<link>` in `<head>` and `<script>` before `</body>`
- `public/app.js` — Inject map `<div>` in `renderUI()`, add `data-station-id` to cards, add `buildPopupContent()` and `initMap()`, call `initMap(data)` after `app.innerHTML` assignment
- `public/style.css` — Add `.map-section` sizing, `.map-pin` / `.map-pin--hero` DivIcon circle styles, `.map-popup` dark theme overrides, `.place-card--highlighted` box-shadow, responsive heights

#### 2d. Add `buildPopupContent()` function

Add this function before `loadColdestPlaces()`. It reuses the existing `renderSourceBadge()`:

```javascript
function buildPopupContent(station, isHero) {
  const badge = renderSourceBadge(station.source, station.stationId, station.sourceRef);
  const tempC = station.tempC.toFixed(1);
  const tempF = ((station.tempC * 9 / 5) + 32).toFixed(1);
  const heroTag = isHero ? '<span class="map-popup-hero-tag">Coldest</span>' : '';
  return `
    <div class="map-popup-content">
      ${heroTag}
      <div class="map-popup-name">${station.name}</div>
      <div class="map-popup-temp">${tempC}°C / ${tempF}°F</div>
      <div class="map-popup-meta">${badge}&nbsp;&bull; ${station.stationId}</div>
    </div>
  `;
}
```

#### 2e. Add `initMap()` function

Add this function immediately after `buildPopupContent()`, before `loadColdestPlaces()`:

```javascript
function initMap(data) {
  const { coldest, top5 } = data;

  // Build ordered list: hero first, then the 5 top-ranked stations
  const allStations = [
    Object.assign({}, coldest, { isHero: true }),
    ...top5.map(s => Object.assign({}, s, { isHero: false })),
  ];

  // Silently skip stations with missing/zero coordinates (DISP-03 caveat)
  const validStations = allStations.filter(s => !(s.latitude === 0 && s.longitude === 0));

  if (validStations.length === 0) return;

  const map = L.map('coldest-map', {
    zoomControl: true,
    scrollWheelZoom: false,  // prevent scroll-hijack on embedded maps
  });

  // CartoDB Dark Matter — no API key, matches site dark theme
  L.tileLayer('https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png', {
    attribution:
      '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors ' +
      '&copy; <a href="https://carto.com/attributions">CARTO</a>',
    subdomains: 'abcd',
    maxZoom: 19,
  }).addTo(map);

  // Hero pin: 16×16 cyan circle (matches --accent-cold: #64b5f6)
  const heroIcon = L.divIcon({
    html: '<span class="map-pin map-pin--hero"></span>',
    className: '',       // clear default white-box class
    iconSize: [16, 16],
    iconAnchor: [8, 8],
    popupAnchor: [0, -10],
  });

  // Regular top-5 pin: 12×12 blue circle
  const regularIcon = L.divIcon({
    html: '<span class="map-pin"></span>',
    className: '',
    iconSize: [12, 12],
    iconAnchor: [6, 6],
    popupAnchor: [0, -8],
  });

  validStations.forEach(station => {
    const icon = station.isHero ? heroIcon : regularIcon;
    const marker = L.marker([station.latitude, station.longitude], { icon });

    marker.bindPopup(buildPopupContent(station, station.isHero), {
      className: 'map-popup',
      maxWidth: 220,
      minWidth: 160,
    });

    marker.on('click', () => {
      // Hero card uses .coldest-card, top-5 use .place-card
      const selector = station.isHero
        ? `.coldest-card[data-station-id="${station.stationId}"]`
        : `.place-card[data-station-id="${station.stationId}"]`;
      const card = document.querySelector(selector);
      if (card) {
        card.scrollIntoView({ behavior: 'smooth', block: 'center' });
        card.classList.add('place-card--highlighted');
        setTimeout(() => card.classList.remove('place-card--highlighted'), 1500);
      }
    });

    marker.addTo(map);
  });

  // Fit the view to all pins; guard against over-zoom on clustered stations
  if (validStations.length === 1) {
    map.setView([validStations[0].latitude, validStations[0].longitude], 6);
  } else {
    const bounds = L.latLngBounds(validStations.map(s => [s.latitude, s.longitude]));
    map.fitBounds(bounds, { padding: [40, 40], maxZoom: 12 });
  }
}
```

#### 2f. Call `initMap(data)` in `loadColdestPlaces()`

In the `try` block of `loadColdestPlaces()`, after the `app.innerHTML = renderUI(data);`
line, add a call to `initMap`. The map container does not exist in the DOM until after
`renderUI()` runs, so the call order is mandatory:

```javascript
    // Render the UI
    app.innerHTML = renderUI(data);
    initMap(data);  // must be called after innerHTML — map container is injected by renderUI()
```

## Threat Model

This is a pure frontend read-only rendering change. No new endpoints, no user input,
no authentication surfaces.

| Concern | Assessment |
|---|---|
| XSS via popup HTML | `station.name` and `station.stationId` injected into innerHTML via template literals — same pattern already used by `renderPlaceCard()` throughout `app.js`. Values originate from the `/api/coldest` JSON response which is Zod-validated server-side (all string fields). NOAA/EC source data has never contained HTML payloads; risk accepted consistent with existing codebase pattern. |
| CDN supply-chain | Leaflet CDN tags include SRI `integrity` hashes pinned to version 1.9.4. If unpkg serves a tampered file the browser will refuse to load it. |
| HTTPS mixed content | `https://{s}.basemaps.cartocdn.com` tiles load over HTTPS; no mixed content on the Render production domain (`https://coldestplaceonearth.onrender.com`). |
| External map tile requests | Tile requests go to CartoDB subdomains (`a–d.basemaps.cartocdn.com`). No user PII or API keys are included in tile URLs. `crossorigin=""` on CDN script/link is correct per SRI spec. |
